HistoryZoomout

About this project

This is a small fun personal project I started as a side hustle. As someone passionate about history, I've always liked to zoom out and see events on a timeline relative to each other, rather than focus on one topic without the context of what else was happening around it. That's why I built History Zoomout.

The code and data for this project are open source and available. Feel free to give feedback and recommend ideas.
